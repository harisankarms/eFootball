# Card sounds

Background tracks for the big cards on Home. Drop a file in this folder with one of these names:

| File | Plays on |
|---|---|
| `potw.mp3` | the Player of the Week card |
| `chenda.mp3` | the chenda card |

`.m4a`, `.aac`, `.ogg`, `.opus` and `.wav` work too (for example `chenda.m4a`), but MP3 or M4A plays everywhere, including iPhones.

A card only shows its speaker button once its file is here, so you can add one and not the other.

Tips:

- **15 to 45 seconds** is plenty. The track loops, so trim it where it can repeat without a jump.
- **Keep it under about 1 MB** (an MP3 at 128 kbps is about 1 MB a minute). Nothing downloads until someone taps the speaker.
- **This repository is public**, so anyone can download what's in it. Your own recordings are fine; think twice before adding songs you don't own.
